Build a simple AI-powered Gmail newsletter aggregator web app.

Goal:
I receive many long newsletters in Gmail across finance, tech, startups, AI, software, and global news. I want the app to automatically scan them, remove noise, identify what actually matters to me, and generate one clean daily digest I can quickly read.

The app should feel like my own personalized intelligence briefing.

Core workflow:
1. Connect Gmail with OAuth.
2. User adds newsletter sender email addresses/domains.
3. App fetches newsletters from Gmail automatically.
4. AI extracts only relevant information.
5. AI combines information across newsletters.
6. App generates one clean daily digest.

Main priorities:
- Startup funding rounds (small and large)
- IPO announcements
- Acquisitions and mergers
- AI developments
- Software and SaaS trends
- Tech industry shifts
- Emerging tools/products
- Automation workflows
- AI tips/tricks/workflows
- Startup ecosystem trends
- Business and technology trends
- Global important news relevant to tech/business

Interests:
- AI
- SaaS
- Fintech
- Automation
- Cybersecurity
- Biotech
- Dev tools
- Defense tech
- Startups
- Big tech
- Enterprise software
- Consumer apps
- Solo builders/indie hackers

Deprioritize:
- Sponsored content
- Ads
- Referral programs
- Generic newsletter intros/outros
- “About us” sections
- Unsubscribe/footer sections
- Creator economy content
- E-commerce content
- Interest rate commentary unless highly important
- Generic market movement updates
- Generic investing advice
- Political filler without business/tech relevance
- Self-promotional content
- Repeated information across newsletters

AI filtering behavior:
The AI should:
- Detect the truly important information
- Remove fluff automatically
- Merge duplicate stories from multiple newsletters
- Rank stories by relevance and importance
- Prefer signal over noise
- Prefer actionable and trend-relevant information
- Generate concise summaries
- Explain briefly why something matters

Daily digest structure:
1. Top Stories
2. Funding Rounds & IPOs
3. AI & Software
4. Startup & Tech Trends
5. Important Takeaways
6. Things To Watch
7. Useful Links

For each story include:
- Short headline
- 2–4 sentence summary
- Why it matters
- Link to original article/newsletter

UI:
Very clean and minimal.
Dashboard should include:
- Newsletter source management
- Daily digest view
- Search
- Archive of past digests
- “Read original article” links
- Optional thumbs up/down feedback for learning preferences

Tech requirements:
- Replit-friendly architecture
- Beginner-friendly code structure
- Frontend + backend
- Gmail OAuth integration
- LLM integration for filtering/summarization
- Database for senders, emails, digests, and preferences

Suggested stack:
- Next.js frontend
- Supabase database/auth
- OpenAI API
- Gmail API
- Tailwind CSS

Important:
Do NOT build a generic summarizer.
This should behave like a personalized AI analyst that filters newsletters into high-signal daily intelligence briefings.

MVP:
1. Gmail OAuth
2. Add newsletter senders
3. Fetch emails from last 24 hours
4. Extract content
5. AI filtering and ranking
6. Generate one daily digest page
7. Save digest history
